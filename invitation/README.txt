CHANDU & PRAVALLIKA ENGAGEMENT INVITATION - VERCEL STARTER

1. Extract this ZIP.
2. Open the extracted Chandu_Pravallika_Vercel_Starter folder in VS Code.
3. Confirm index.html is directly inside the folder (not inside another nested folder).
4. Test locally: open index.html in a browser, or use VS Code Live Server.
5. Create a GitHub repository and upload index.html at the repository ROOT.
6. In Vercel, import that GitHub repository.
7. Set Framework Preset to Other. Do not set a build command. Keep the deployment root at the repository root.
8. Deploy. The site homepage should be served from /index.html at the domain root.

The invitation HTML includes embedded image data. It still loads web fonts from Google Fonts and uses a Google Maps link, so those features need an internet connection.
